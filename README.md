## Задания

### Задание 1 — Текстовый флаг (1 балл)

**Файл:** `ex1.py`

Приложение «Текстовый флаг». Пользователь выбирает цвет для каждой из трёх полос флага с помощью `QRadioButton` из нескольких вариантов. После нажатия кнопки «Нарисовать» выводится сообщение с выбранными цветами.

**Пример вывода:** `Красный, Зелёный, Белый`

Размер окна зафиксирован через `setFixedSize()` — изменение размеров запрещено.

**Используемые виджеты:** `QGroupBox`, `QRadioButton`, `QPushButton`, `QMessageBox`, `QVBoxLayout`, `QHBoxLayout`

### Задание 2 — Ежедневник (3 балла)

**Файл:** `ex2.py`

Программа-ежедневник. Пользователь вводит название события, выбирает дату через `QCalendarWidget` и время через `QTimeEdit`, нажимает кнопку «Добавить». Событие появляется в `QListWidget` и автоматически сортируется по возрастанию даты и времени.

Для хранения событий используется список кортежей `(QDateTime, str)`, который сортируется методом `sort()` по ключу даты.

**Используемые виджеты:** `QLineEdit`, `QCalendarWidget`, `QTimeEdit`, `QPushButton`, `QListWidget`, `QVBoxLayout`, `QHBoxLayout`

### Задание 4 — Игра «Псевдоним» (4 балла)

**Файл:** `ex4.py`

Графический интерфейс для игры «Псевдоним». Правила:

- В куче лежит `N` камней (не менее 5).
- Игроки по очереди берут от 1 до 3 камней.
- Выигрывает тот, кто заберёт последний камень.
- Игрок ходит первым, против него играет компьютер.

**Стратегия ИИ:**  
Компьютер всегда выигрывает, когда это возможно. После хода игрока ИИ оставляет в куче количество камней, кратное 4 (то есть `count % 4 == 1` после хода игрока), что гарантирует победу при правильной игре.

**Обработка ошибок:**  
Проверяется корректность ввода (число от 1 до 3 и не больше оставшихся камней).

**Используемые виджеты:** `QLabel`, `QLineEdit`, `QPushButton`, `QMessageBox`, `QVBoxLayout`

### Задание 5 — Антиплагиат (4 балла)

**Файл:** `ex5.py`

Программа для простейшей проверки текстов на антиплагиат. На форме размещены:

- `QDoubleSpinBox` для задания порога срабатывания антиплагиата (в процентах).
- Два `QPlainTextEdit` для ввода сравниваемых текстов.
- Кнопка «Проверить» для запуска сравнения.
- `QStatusBar` для отображения результата с цветовой индикацией.

**Алгоритм сравнения:**  
Тексты разбиваются на слова с помощью регулярного выражения, приводятся к нижнему регистру, из них формируются множества. Схожесть вычисляется как отношение мощности пересечения множеств к мощности большего множества:

```
similarity = |A ∩ B| / max(|A|, |B|) * 100%
```

**Цветовая индикация:**
- Красный фон — схожесть превышает порог (плагиат).
- Зелёный фон — схожесть ниже порога.

**Используемые виджеты:** `QMainWindow`, `QDoubleSpinBox`, `QPlainTextEdit`, `QPushButton`, `QLabel`, `QStatusBar`, `QVBoxLayout`, `QHBoxLayout`

## Установка и запуск

### Требования

- Python 3.9 или выше
- PyQt6

### Установка зависимостей

```bash
pip install PyQt6
```

### Запуск

Каждый файл запускается отдельно:

```bash
python ex1.py
python ex2.py
python ex3.py
python ex4.py
python ex5.py
```

## Примечания

- Все приложения используют модульную структуру с классом-наследником `QWidget` или `QMainWindow`.
- Для компоновки элементов применяются `QVBoxLayout`, `QHBoxLayout` и `QGroupBox`.
- Обработчики событий подключаются через сигнал `clicked`.
- Задание 5 использует `QStatusBar` для вывода результата с цветовой подсветкой через `setStyleSheet`.
